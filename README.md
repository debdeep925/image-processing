# React + Node.js Application

This project consists of:

- Frontend: React (Vite)
- Backend: Node.js + Express

## Prerequisites

- Node.js (v18+)
- npm

## Installation

Install dependencies for both frontend and backend:

```bash
cd frontend
npm install

cd backend
npm install
```

## Run the Application

### Start Backend

```bash
cd backend
npm run dev
```

Backend runs on: `http://localhost:5000`

### Start Frontend

Open a new terminal:

```bash
cd frontend
npm run dev
```

Frontend runs on: `http://localhost:5173`

## Build Frontend

```bash
cd frontend
npm run build
```
